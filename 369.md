一、 系统架构与功能特性清单
1. 扫码挪车前台交互 (/?id=xxx)
- 6 大常用事由 6 宫格排布：
  - 🚗 阻碍通道：预设“您的车辆阻碍通行，请协助挪车”
  - ⏰ 超时停放：预设“车辆停放已超时，请尽快挪车”
  - 💥 车辆剐蹭：预设“您的车辆发生剐蹭，请尽快前来查看处理”
  - 🪟 车窗未关：预设“车窗/天窗未关好，请留意”
  - 💡 车灯未关：预设“车灯未熄灭，请留意电瓶耗尽”
  - 📝 其他事由：预设“您好，有关于您爱车的事宜需要与您沟通”
- 事由与输入框独立手机号弹窗控制：
  - 后台针对上述 6 个事由 + 手动留言输入框均支持单独配置“是否强制输入手机号”。
  - 善意提醒（如车灯未关）可设置不弹窗直接通知；紧急挪车可开启必填手机号。
- 空点击强拦截机制：
  - 进入页面未点击任何预设事由且输入框留空时，点击“通知车主”将立即弹窗拦截：⚠️ 请先点击选择上方的预设事由，或在输入框中填写说明！，杜绝误触或恶意空白发送。
- 极速非阻塞响应 (ctx.waitUntil)：
  - 校验通过后，后端耗时约 30~50 毫秒即可返回成功，前台秒弹内置的高颜值成功提示弹窗；邮件发送与 ntfy 推送转入边缘后台并行执行，彻底消除几秒钟的卡顿等待。
- 车主直拨电话控制：
  - 仅当车主在后台勾选“允许前台一键拨号”并填写电话时才展示绿色拨打按钮；未勾选则前台彻底隐藏。
- 主页底部注册入口：
  - 页面最底部常驻展示“我也要制作挪车二维码 →”，方便他人扫码后快速注册。
- 车主账号封禁联动：
  - 若车主账号被管理员在后台停用，其名下二维码扫码时自动展示友好拦截页（“该车辆挪车服务已被管理员暂停，暂不可用”），禁止发送任何消息。
2. 多租户配额与权限分级系统
- 超级管理员：
  - 首位注册者自动赋予管理员权限，终身免邀请码。
  - 拥有系统全权控制台：用户权限管理、全局车辆查询、邀请码管理、邮件发信测试、全渠道审计日志与系统配置。
- 用户权限管理 (Admin 专属)：
  - 集中展示所有注册用户列表、车辆数、配额上限及启用状态。
  - 车辆配额调控：可单独修改各用户的最大允许绑定车辆数（max_cars）。
  - 一键启/停用账号：停用后该用户既无法登录后台，其名下的所有挪车码也会即刻失效。
- 普通车主用户：
  - 登录后仅可进入“我的车辆与二维码”管理自有名下的车辆，数据严格隔离，无法查看他人车辆或系统配置。
  - 添加车辆超过配额上限时受到系统拦截。
- 注册邀请码机制：
  - 后台全局开关：可自由切换是否必须凭邀请码注册。
  - 邀请码生成器：支持随机生成或添加自定义码（如 VIP888），一次性核销作废。
3. 全渠道即时通知分发引擎
- ntfy 推送（强力支持）：
  - 支持自建服务器 URL（如 https://ntfy.yourdomain.xyz）或官方 https://ntfy.sh。
  - 支持私有实例 Bearer Token 鉴权。
  - 默认高优先级锁屏通知，正文携带挪车人手机号，且内置 【📞 回拨对方 (手机号)】 动作按钮，车主在通知栏点一下即可回拨。
- 富文本卡片邮件：
  - 响应式卡片 HTML 布局，默认走 SMTP 直连（Worker 内置 TCP/TLS，支持 465 SSL 与 587 STARTTLS），可对接 QQ 邮箱、163、Gmail、企业邮局等任意标准 SMTP 服务，无第三方发信 API 依赖；同时保留 Resend、Brevo 作为可选驱动。
- 主流 IM 机器人全覆盖：
  - 微信 (WxPusher)、iOS (Bark)、飞书机器人、钉钉机器人、企业微信机器人、QQ 机器人 (OneBot/NapCat)。

/**
 * 智能挪车 + 邮件通知 + 自建 ntfy 全渠道系统 (最终归档版)
 * 依赖绑定:
 *   - KV 命名空间: DATA

  async fetch(request, env, ctx) {
    const url = new URL(request.url);
    const path = url.pathname;
    const method = request.method;

    if (method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
          "Access-Control-Allow-Headers": "Content-Type, Authorization"
        }
      });
    }

    try {
      // 1. 公共访问：挪车展示页面if (path === "/" || path === "/move") {
        const carId = url.searchParams.get("id");
        return await renderCarPage(carId, env);
      }

      // 2. 挪车通知触发 API (异步非阻塞极速响应)if (path === "/api/notify" && method === "POST") {
        return await handleCarNotify(request, env, ctx);
      }

      // 3. 独立邮件发送 APIif (path === "/api/send-email" && method === "POST") {
        return await handleDirectEmail(request, env);
      }

      // 4. 注册与登录if (path === "/api/register" && method === "POST") {
        return await handleRegister(request, env);
      }
      if (path === "/api/login" && method === "POST") {
        return await handleLogin(request, env);
      }

      // 5. 鉴权业务接口if (path.startsWith("/api/user/") || path.startsWith("/api/admin/")) {
        const auth = await authenticate(request, env);
        if (!auth.ok) return jsonResponse({ error: "未登录或登录已过期" }, 401);
        const { user } = auth;

        if (path === "/api/user/cars" && method === "GET") return await getCars(user, env);
        if (path === "/api/user/cars" && method === "POST") return await saveCar(request, user, env);
        if (path === "/api/user/cars/delete" && method === "POST") return await deleteCar(request, user, env);

        if (path.startsWith("/api/admin/")) {
          if (user.role !== 'admin') return jsonResponse({ error: "权限不足：仅管理员可访问！" }, 403);

          if (path === "/api/admin/users" && method === "GET") return await adminGetUsers(env);
          if (path === "/api/admin/users/update" && method === "POST") return await adminUpdateUser(request, env);
          if (path === "/api/admin/users/delete" && method === "POST") return await adminDeleteUser(request, env);
          if (path === "/api/admin/logs" && method === "GET") return await getLogs(env);
          if (path === "/api/admin/settings" && method === "GET") return await getSettings(env);
          if (path === "/api/admin/settings" && method === "POST") return await saveSettings(request, env);
          if (path === "/api/admin/invites" && method === "GET") return await getInvites(env);
          if (path === "/api/admin/invites" && method === "POST") return await createInvite(request, env);
          if (path === "/api/admin/invites/delete" && method === "POST") return await deleteInvite(request, env);
        }
      }

      // 6. 控制台页面if (path === "/admin" || path === "/login" || path === "/register") {
        return new Response(ADMIN_HTML, { headers: { "Content-Type": "text/html;charset=UTF-8" } });
      }

      return new Response("Not Found", { status: 404 });
    } catch (err) {
      return jsonResponse({ error: err.message }, 500);
    }
  }
};

/* ---------------- 全渠道并发推送引擎 ---------------- */async function sendEmailMessage(env, { to, subject, htmlContent }) {
  const provider = (await getSysConfig(env, "email_provider")) || "mailchannels";
  if (provider === "resend") {
    const apiKey = await getSysConfig(env, "resend_api_key");
    const fromEmail = (await getSysConfig(env, "resend_from_email")) || "notify@resend.dev";
    const res = await fetch("https://api.resend.com/emails", {
      method: "POST",
      headers: { "Authorization": `Bearer ${apiKey}`, "Content-Type": "application/json" },
      body: JSON.stringify({ from: fromEmail, to: [to], subject, html: htmlContent })
    });
    return res.ok;
  } else if (provider === "brevo") {
    const apiKey = await getSysConfig(env, "brevo_api_key");
    const res = await fetch("https://api.brevo.com/v3/smtp/email", {
      method: "POST",
      headers: { "api-key": apiKey, "Content-Type": "application/json" },
      body: JSON.stringify({
        sender: { name: "挪车与提醒系统", email: "notify@notify-service.local" },
        to: [{ email: to }],
        subject,
        htmlContent
      })
    });
    return res.ok;
  } else {
    const res = await fetch("https://api.mailchannels.net/tx/v1/send", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        personalizations: [{ to: [{ email: to }] }],
        from: { email: "no-reply@cf-workers.local", name: "挪车通知中心" },
        subject,
        content: [{ type: "text/html", value: htmlContent }]
      })
    });
    return res.ok || res.status === 202;
  }
}

        const headers = { "Content-Type": "application/json" };

          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ appToken: car.wxpusher_token, content: messageText, contentType: 1, uids: [car.wxpusher_uid] })

      } catch { return { channel: "Bark", ok: false }; }

  }

    tasks.push((async () => {
      try {
        const res = await fetch(car.feishu_webhook, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ msg_type: "text", content: { text: messageText } })
        });
        return { channel: "Feishu", ok: res.ok };
      } catch { return { channel: "Feishu", ok: false }; }
    })());
  }

  // 6. 钉钉if (channels.includes("dingtalk") && car.dingtalk_webhook) {
    tasks.push((async () => {
      try {
        const res = await fetch(car.dingtalk_webhook, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ msgtype: "text", text: { content: messageText } })

    tasks.push((async () => {
      try {
        const res = await fetch(car.wecom_webhook, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ msgtype: "text", text: { content: messageText } })
        });
        return { channel: "WeCom", ok: res.ok };
      } catch { return { channel: "WeCom", ok: false }; }
    })());
  }

  // 8. QQif (channels.includes("qq") && car.qq_webhook && car.qq_target_id) {
    tasks.push((async () => {
      try {
        const res = await fetch(car.qq_webhook.replace(/\/+$/, "") + "/send_msg", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ user_id: car.qq_target_id, message: messageText })
        });
        return { channel: "QQ", ok: res.ok };
      } catch { return { channel: "QQ", ok: false }; }
    })());
  }

  const settled = await Promise.allSettled(tasks);
  return settled.map(s => s.status === "fulfilled" ? s.value : { channel: "Unknown", ok: false });
}

/* ---------------- 业务接口与逻辑校验 ---------------- */function parsePhoneConfig(val) {
  const defaults = { blocking: true, timeout: true, window: false, lights: false, scratch: true, other: false, custom: true };
  if (!val) return defaults;
  if (typeof val === 'string' && val.startsWith('{')) {
    try { return { ...defaults, ...JSON.parse(val) }; } catch (e) { return defaults; }
  }
  if (val === 1 || val === "1") return { blocking: true, timeout: true, window: true, lights: true, scratch: true, other: true, custom: true };
  if (val === 0 || val === "0") return { blocking: false, timeout: false, window: false, lights: false, scratch: false, other: false, custom: false };
  return defaults;
}

async function handleCarNotify(request, env, ctx) {
  const { carId, message, callerPhone, reasonKey } = await request.json();
  const clientIp = request.headers.get("CF-Connecting-IP") || "127.0.0.1";

  // 后端严格防御：必须选择事由或有输入留言内容if (!reasonKey && (!message || !message.trim())) {
    return jsonResponse({ error: "请先选择挪车事由或输入留言说明！" }, 400);
  }

  const effectiveReasonKey = reasonKey || 'custom';

  const car = await env.DB.prepare(`
    SELECT cars.*, users.status as owner_status 
    FROM cars 
    LEFT JOIN users ON cars.user_id = users.id 
    WHERE cars.id = ?
  `).bind(carId).first();

  if (!car) return jsonResponse({ error: "车辆不存在" }, 404);

  if (car.owner_status === 0) {
    return jsonResponse({ error: "该车辆挪车服务已被管理员暂停，暂不可用！" }, 403);
  }

  const phoneConfig = parsePhoneConfig(car.require_caller_phone);
  const isRequired = phoneConfig[effectiveReasonKey];
  if (isRequired) {
    if (!callerPhone || !callerPhone.trim()) {
      return jsonResponse({ error: "该事由需要提供您的联系手机号！" }, 400);
    }
  }

  const cooldownSec = parseInt((await getSysConfig(env, "cooldown_seconds")) || "60");
  const lockKey = `cooldown:${carId}:${clientIp}`;
  const isLocked = await env.DATA.get(lockKey);
  if (isLocked) {
    return jsonResponse({ error: `发送过于频繁，请等待 ${cooldownSec} 秒后再试` }, 429);
  }

  await env.DATA.put(lockKey, "1", { expirationTtl: cooldownSec });

  ctx.waitUntil((async () => {
    try {
      const results = await dispatchNotifications(car, env, message, (callerPhone || "").trim(), clientIp);
      await env.DB.prepare(
        "INSERT INTO notify_logs (source, target, channel, status, detail, ip) VALUES (?, ?, ?, ?, ?, ?)"
      ).bind("car_notify", car.plate_no, JSON.stringify(results.map(r => r.channel)), "success", `电话:${callerPhone || '未提供'} | ${message || "无留言"}`, clientIp).run();
    } catch (e) {
      console.error("后台异步推送异常:", e);
    }
  })());

  return jsonResponse({ success: true, message: "通知已即时发出" });
}

async function hashPassword(str) {
  const buf = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(str));
  return Array.from(new Uint8Array(buf)).map(b => b.toString(16).padStart(2, '0')).join('');
}

async function authenticate(request, env) {
  const auth = request.headers.get("Authorization");
  if (!auth) return { ok: false };
  const token = auth.replace("Bearer ", "");
  const sessionStr = await env.DATA.get(`session:${token}`);
  if (!sessionStr) return { ok: false };
  const sessionUser = JSON.parse(sessionStr);

  const user = await env.DB.prepare("SELECT id, username, role, status, max_cars FROM users WHERE id = ?").bind(sessionUser.id).first();
  if (!user || user.status === 0) return { ok: false };

  return { ok: true, user };
}

/* ---------------- 登录注册与用户管理 ---------------- */async function handleRegister(request, env) {
  const { username, password, inviteCode } = await request.json();
  if (!username || !password) return jsonResponse({ error: "请输入用户名和密码" }, 400);

  const userCount = await env.DB.prepare("SELECT COUNT(*) as count FROM users").first();
  const isFirstUser = (userCount ? userCount.count : 0) === 0;

  if (!isFirstUser) {
    const requireInvite = (await getSysConfig(env, "require_invite_code")) === "1";
    if (requireInvite) {
      if (!inviteCode || !inviteCode.trim()) {
        return jsonResponse({ error: "本站已开启邀请注册，请输入邀请码！" }, 400);
      }
      const validCode = await env.DB.prepare("SELECT * FROM invite_codes WHERE code = ? AND is_used = 0").bind(inviteCode.trim()).first();
      if (!validCode) {
        return jsonResponse({ error: "邀请码无效或已被使用，请联系管理员！" }, 400);
      }
      await env.DB.prepare("UPDATE invite_codes SET is_used = 1 WHERE id = ?").bind(validCode.id).run();
    }
  }

  const role = isFirstUser ? 'admin' : 'user';
  const hashed = await hashPassword(password);
  try {
    await env.DB.prepare("INSERT INTO users (username, password, role, max_cars, status) VALUES (?, ?, ?, ?, 1)")
      .bind(username, hashed, role, isFirstUser ? 999 : 3).run();
    return jsonResponse({ success: true, role });
  } catch (e) {
    return jsonResponse({ error: "用户名已存在" }, 400);
  }
}

async function handleLogin(request, env) {
  const { username, password } = await request.json();
  const hashed = await hashPassword(password);
  const user = await env.DB.prepare("SELECT id, username, role, status, max_cars FROM users WHERE username = ? AND password = ?").bind(username, hashed).first();
  if (!user) return jsonResponse({ error: "用户名或密码错误" }, 401);

  if (user.status === 0) {
    return jsonResponse({ error: "该账号已被管理员停用，无法登录系统！" }, 403);
  }

  const token = crypto.randomUUID();
  await env.DATA.put(`session:${token}`, JSON.stringify(user), { expirationTtl: 86400 * 7 });
  return jsonResponse({ token, user });
}

/* ---------------- 原生 SMTP 直连发信引擎（worker 内置 TCP/TLS，不经过任何第三方发信 API） ---------------- */
function _utf8ToB64(str) {
  const bytes = new TextEncoder().encode(String(str));
  let bin = "";
  for (let i = 0; i < bytes.length; i++) bin += String.fromCharCode(bytes[i]);
  return btoa(bin);
}

function _b64Lines(str, width = 76) {
  const s = _utf8ToB64(str);
  const out = [];
  for (let i = 0; i < s.length; i += width) out.push(s.substr(i, width));
  return out.join("\r\n");
}

function _rfc2047(str) {
  return "=?UTF-8?B?" + _utf8ToB64(str) + "?=";
}

function _withTimeout(promise, ms, label) {
  let timer;
  const timeout = new Promise((_, reject) => {
    timer = setTimeout(() => reject(new Error(label + " 超时")), ms);
  });
  return Promise.race([promise, timeout]).finally(() => clearTimeout(timer));
}

async function smtpSendMail(cfg, { to, subject, html }) {
  const host = String(cfg.host || "").trim();
  const port = parseInt(String(cfg.port || "465"), 10) || 465;
  const user = String(cfg.user || "").trim();
  const pass = String(cfg.pass || "");
  const fromEmail = String(cfg.from || user).trim();
  const fromName = String(cfg.fromName || "挪车通知中心").trim();
  const secure = String(cfg.secure || (port === 465 ? "ssl" : "starttls")).toLowerCase();

  if (!host) throw new Error("未配置 SMTP 服务器地址");
  if (!user || !pass) throw new Error("未配置 SMTP 邮箱账号或授权码");
  if (!fromEmail) throw new Error("未配置发件邮箱");
  if (!to) throw new Error("收件人为空");

  const ehloName = fromEmail.split("@")[1] || "localhost";
  let socket = connect({ hostname: host, port }, { secureTransport: secure === "ssl" ? "on" : "starttls" });
  const encoder = new TextEncoder();
  const decoder = new TextDecoder();
  let buffer = "";
  let writer = null;
  let reader = null;
  let finished = false;

  const openStreams = () => {
    writer = socket.writable.getWriter();
    reader = socket.readable.getReader();
  };

  const closeAll = async () => {
    if (finished) return;
    finished = true;
    try { if (reader) reader.cancel(); } catch (e) {}
    try { if (writer) writer.close(); } catch (e) {}
    try { socket.close(); } catch (e) {}
  };

  const readReply = async () => {
    let text = "";
    let code = 0;
    while (true) {
      let idx = buffer.indexOf("\r\n");
      while (idx === -1) {
        const chunk = await _withTimeout(reader.read(), 15000, "SMTP 读取");
        if (chunk.done) throw new Error("SMTP 连接被服务器关闭");
        buffer += decoder.decode(chunk.value, { stream: true });
        idx = buffer.indexOf("\r\n");
      }
      const line = buffer.slice(0, idx);
      buffer = buffer.slice(idx + 2);
      if (!text) code = parseInt(line.slice(0, 3), 10);
      text += (text ? "\n" : "") + line;
      if (line.length < 4 || line.charAt(3) !== "-") break;
    }
    return { code, text };
  };

  const sendLine = async (line) => {
    await _withTimeout(writer.write(encoder.encode(line + "\r\n")), 15000, "SMTP 写入");
  };

  const expect = async (codes, stage) => {
    const r = await readReply();
    if (!codes.includes(r.code)) throw new Error(stage + " 失败 [" + r.code + "] " + r.text);
    return r;
  };

  try {
    openStreams();
    await expect([220], "连接握手");

    await sendLine("EHLO " + ehloName);
    let ehlo = await expect([250], "EHLO");

    if (secure !== "ssl") {
      await sendLine("STARTTLS");
      await expect([220], "STARTTLS");
      try { reader.releaseLock(); } catch (e) {}
      try { writer.releaseLock(); } catch (e) {}
      socket = socket.startTls();
      buffer = "";
      openStreams();
      await sendLine("EHLO " + ehloName);
      ehlo = await expect([250], "EHLO(TLS)");
    }

    const caps = (ehlo.text || "").toUpperCase();
    if (caps.includes("AUTH")) {
      if (caps.includes("LOGIN")) {
        await sendLine("AUTH LOGIN");
        await expect([334], "AUTH LOGIN");
        await sendLine(_utf8ToB64(user));
        await expect([334], "AUTH 账号");
        await sendLine(_utf8ToB64(pass));
        await expect([235], "AUTH 授权码");
      } else {
        await sendLine("AUTH PLAIN " + _utf8ToB64("\u0000" + user + "\u0000" + pass));
        await expect([235], "AUTH PLAIN");
      }
    }

    await sendLine("MAIL FROM:<" + fromEmail + ">");
    await expect([250], "MAIL FROM");

    await sendLine("RCPT TO:<" + to + ">");
    await expect([250, 251], "RCPT TO");

    await sendLine("DATA");
    await expect([354], "DATA");

    const dateStr = new Date().toUTCString().replace("GMT", "+0000");
    const msgId = "<" + Date.now() + "." + Math.random().toString(36).slice(2) + "@" + ehloName + ">";
    const headers = [
      "From: " + _rfc2047(fromName) + " <" + fromEmail + ">",
      "To: <" + to + ">",
      "Subject: " + _rfc2047(subject || "通知"),
      "Date: " + dateStr,
      "Message-ID: " + msgId,
      "MIME-Version: 1.0",
      "Content-Type: text/html; charset=UTF-8",
      "Content-Transfer-Encoding: base64"
    ].join("\r\n");

    await sendLine(headers + "\r\n\r\n" + _b64Lines(html || "") + "\r\n.");
    await expect([250], "正文投递");

    try { await sendLine("QUIT"); } catch (e) {}
    return true;
  } finally {
    await closeAll();
  }
}

async function sendEmailMessage(env, { to, subject, htmlContent }) {
  const provider = (await getSysConfig(env, "email_provider")) || "smtp";

  if (provider === "smtp") {
    try {
      const keys = ["smtp_host", "smtp_port", "smtp_user", "smtp_pass", "smtp_from_email", "smtp_from_name", "smtp_secure"];
      const vals = await Promise.all(keys.map((k) => getSysConfig(env, k)));
      const cfg = {
        host: vals[0],
        port: vals[1],
        user: vals[2],
        pass: vals[3],
        from: vals[4],
        fromName: vals[5],
        secure: vals[6]
      };
      await smtpSendMail(cfg, { to, subject, html: htmlContent });
      return true;
    } catch (e) {
      console.error("SMTP 直连发信失败:", (e && e.message) || e);
      return false;
    }
  }

  if (provider === "resend") {
    const apiKey = await getSysConfig(env, "resend_api_key");
    const fromEmail = (await getSysConfig(env, "resend_from_email")) || "notify@resend.dev";
    const res = await fetch("https://api.resend.com/emails", {
      method: "POST",
      headers: { "Authorization": `Bearer ${apiKey}`, "Content-Type": "application/json" },
      body: JSON.stringify({ from: fromEmail, to: [to], subject, html: htmlContent })
    });
    return res.ok;
  }

  if (provider === "brevo") {
    const apiKey = await getSysConfig(env, "brevo_api_key");
    const res = await fetch("https://api.brevo.com/v3/smtp/email", {
      method: "POST",
      headers: { "api-key": apiKey, "Content-Type": "application/json" },
      body: JSON.stringify({
        sender: { name: "挪车与提醒系统", email: "notify@notify-service.local" },
        to: [{ email: to }],
        subject,
        htmlContent
      })
    });
    return res.ok;
  }

  const res = await fetch("https://api.mailchannels.net/tx/v1/send", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      personalizations: [{ to: [{ email: to }] }],
      from: { email: "no-reply@cf-workers.local", name: "挪车通知中心" },
      subject,
      content: [{ type: "text/html", value: htmlContent }]
    })
  });
  return res.ok || res.status === 202;
}

/* ---------------- 业务接口与逻辑校验 ---------------- */
function parsePhoneConfig(val) {
  const defaults = { blocking: true, timeout: true, window: false, lights: false, scratch: true, other: false, custom: true };
  if (!val) return defaults;
  if (typeof val === 'string' && val.startsWith('{')) {
    try { return { ...defaults, ...JSON.parse(val) }; } catch (e) { return defaults; }
  }
  if (val === 1 || val === "1") return { blocking: true, timeout: true, window: true, lights: true, scratch: true, other: true, custom: true };
  if (val === 0 || val === "0") return { blocking: false, timeout: false, window: false, lights: false, scratch: false, other: false, custom: false };
  return defaults;
}

async function handleCarNotify(request, env, ctx) {
  const { carId, message, callerPhone, reasonKey } = await request.json();
  const clientIp = request.headers.get("CF-Connecting-IP") || "127.0.0.1";

  // 后端严格防御：必须选择事由或有输入留言内容
  if (!reasonKey && (!message || !message.trim())) {
    return jsonResponse({ error: "请先选择挪车事由或输入留言说明！" }, 400);
  }

  const effectiveReasonKey = reasonKey || 'custom';

  const car = await env.DB.prepare(`
    SELECT cars.*, users.status as owner_status 
    FROM cars 
    LEFT JOIN users ON cars.user_id = users.id 
    WHERE cars.id = ?
  `).bind(carId).first();

  if (!car) return jsonResponse({ error: "车辆不存在" }, 404);

  if (car.owner_status === 0) {
    return jsonResponse({ error: "该车辆挪车服务已被管理员暂停，暂不可用！" }, 403);
  }

  const phoneConfig = parsePhoneConfig(car.require_caller_phone);
  const isRequired = phoneConfig[effectiveReasonKey];
  if (isRequired) {
    if (!callerPhone || !callerPhone.trim()) {
      return jsonResponse({ error: "该事由需要提供您的联系手机号！" }, 400);
    }
  }

  const cooldownSec = parseInt((await getSysConfig(env, "cooldown_seconds")) || "60");
  const lockKey = `cooldown:${carId}:${clientIp}`;
  const isLocked = await env.DATA.get(lockKey);
  if (isLocked) {
    return jsonResponse({ error: `发送过于频繁，请等待 ${cooldownSec} 秒后再试` }, 429);
  }

  await env.DATA.put(lockKey, "1", { expirationTtl: cooldownSec });

  ctx.waitUntil((async () => {
    try {
      const results = await dispatchNotifications(car, env, message, (callerPhone || "").trim(), clientIp);
      await env.DB.prepare(
        "INSERT INTO notify_logs (source, target, channel, status, detail, ip) VALUES (?, ?, ?, ?, ?, ?)"
      ).bind("car_notify", car.plate_no, JSON.stringify(results.map(r => r.channel)), "success", `电话:${callerPhone || '未提供'} | ${message || "无留言"}`, clientIp).run();
    } catch (e) {
      console.error("后台异步推送异常:", e);
    }
  })());

  return jsonResponse({ success: true, message: "通知已即时发出" });
}

async function hashPassword(str) {
  const buf = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(str));
  return Array.from(new Uint8Array(buf)).map(b => b.toString(16).padStart(2, '0')).join('');
}

async function authenticate(request, env) {
  const auth = request.headers.get("Authorization");
  if (!auth) return { ok: false };
  const token = auth.replace("Bearer ", "");
  const sessionStr = await env.DATA.get(`session:${token}`);
  if (!sessionStr) return { ok: false };
  const sessionUser = JSON.parse(sessionStr);

  const user = await env.DB.prepare("SELECT id, username, role, status, max_cars FROM users WHERE id = ?").bind(sessionUser.id).first();
  if (!user || user.status === 0) return { ok: false };

  return { ok: true, user };
}

async function handleRegister(request, env) {
  const { username, password, inviteCode } = await request.json();
  if (!username || !password) return jsonResponse({ error: "请输入用户名和密码" }, 400);

  const userCount = await env.DB.prepare("SELECT COUNT(*) as count FROM users").first();
  const isFirstUser = (userCount ? userCount.count : 0) === 0;

  if (!isFirstUser) {
    const requireInvite = (await getSysConfig(env, "require_invite_code")) === "1";
    if (requireInvite) {
      if (!inviteCode || !inviteCode.trim()) {
        return jsonResponse({ error: "本站已开启邀请注册，请输入邀请码！" }, 400);
      }
      const validCode = await env.DB.prepare("SELECT * FROM invite_codes WHERE code = ? AND is_used = 0").bind(inviteCode.trim()).first();
      if (!validCode) {
        return jsonResponse({ error: "邀请码无效或已被使用，请联系管理员！" }, 400);
      }
      await env.DB.prepare("UPDATE invite_codes SET is_used = 1 WHERE id = ?").bind(validCode.id).run();
    }
  }

  const role = isFirstUser ? 'admin' : 'user';
  const hashed = await hashPassword(password);
  try {
    await env.DB.prepare("INSERT INTO users (username, password, role, max_cars, status) VALUES (?, ?, ?, ?, 1)")
      .bind(username, hashed, role, isFirstUser ? 999 : 3).run();
    return jsonResponse({ success: true, role });
  } catch (e) {
    return jsonResponse({ error: "用户名已存在" }, 400);
  }
}

async function handleLogin(request, env) {
  const { username, password } = await request.json();
  const hashed = await hashPassword(password);
  const user = await env.DB.prepare("SELECT id, username, role, status, max_cars FROM users WHERE username = ? AND password = ?").bind(username, hashed).first();
  if (!user) return jsonResponse({ error: "用户名或密码错误" }, 401);

  if (user.status === 0) {
    return jsonResponse({ error: "该账号已被管理员停用，无法登录系统！" }, 403);
  }

  const token = crypto.randomUUID();
  await env.DATA.put(`session:${token}`, JSON.stringify(user), { expirationTtl: 86400 * 7 });
  return jsonResponse({ token, user });
}

  const settings = await request.json();
  for (const [k, v] of Object.entries(settings)) {
    await env.DB.prepare("INSERT OR REPLACE INTO sys_config (key, value) VALUES (?, ?)").bind(k, String(v ?? '')).run();
  }
  return jsonResponse({ success: true });
}

async function getInvites(env) {
  const { results } = await env.DB.prepare("SELECT * FROM invite_codes ORDER BY created_at DESC").all();
  return jsonResponse(results);
}

async function createInvite(request, env) {
  const { code } = await request.json();
  const inviteCode = code ? code.trim() : 'INV-' + Math.random().toString(36).substr(2, 6).toUpperCase();
  try {
    await env.DB.prepare("INSERT INTO invite_codes (code) VALUES (?)").bind(inviteCode).run();
    return jsonResponse({ success: true, code: inviteCode });
  } catch (e) {
    return jsonResponse({ error: "邀请码已存在" }, 400);
  }
}

async function deleteInvite(request, env) {
  const { id } = await request.json();
  await env.DB.prepare("DELETE FROM invite_codes WHERE id = ?").bind(id).run();
  return jsonResponse({ success: true });
}

    const { createApp } = Vue;

      data() {
        return {

        async handleAuth() {
          const endpoint = this.isRegister ? '/api/register' : '/api/login';
          const res = await fetch(endpoint, {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(this.authForm)
          });
          const data = await res.json();
          if (res.ok) {
            if (this.isRegister) {
              alert('注册成功！' + (data.role === 'admin' ? '您是首位注册者，已赋予超级管理员权限！' : '请使用该账号登录后台管理您的爱车！'));
              this.isRegister = false;
            } else {
              this.token = data.token;
              this.user = data.user;
              localStorage.setItem('token', data.token);
              localStorage.setItem('user', JSON.stringify(data.user));
              this.loadDashboardData();
            }
          } else {
            alert(data.error);
          }
        },
        logout() {
          this.token = '';
          localStorage.clear();
        },
        async loadDashboardData() {
          const headers = { 'Authorization': 'Bearer ' + this.token };

          const carsRes = await fetch('/api/user/cars', { headers });
          this.cars = await carsRes.json();

          if (this.user.role === 'admin') {
            const [usersRes, logsRes, settingsRes, invitesRes] = await Promise.all([
              fetch('/api/admin/users', { headers }),
              fetch('/api/admin/logs', { headers }),
              fetch('/api/admin/settings', { headers }),
              fetch('/api/admin/invites', { headers })
            ]);
            this.userList = await usersRes.json();
            this.logs = await logsRes.json();
            this.settings = await settingsRes.json();
            this.invites = await invitesRes.json();
          }

          this.renderAllQrs();
        },
        renderAllQrs() {
          setTimeout(() => {
            this.cars.forEach(car => {
              const el = document.getElementById('qr-' + car.id);
              if (el) {
                QRCode.toCanvas(el, window.location.origin + '/?id=' + car.id, { width: 96, margin: 1 }, function (error) {
                  if (error) console.error(error);
                });
              }
            });
          }, 150);
        },
        downloadQr(carId, plateNo) {
          const canvas = document.getElementById('qr-' + carId);
          if (!canvas) return;
          const a = document.createElement('a');
          a.download = plateNo + '-挪车码.png';
          a.href = canvas.toDataURL('image/png');
          a.click();
        },
        genNtfyTopic() {
          const chars = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
          const buf = new Uint32Array(9);
          (window.crypto || crypto).getRandomValues(buf);
          let out = '';
          for (let i = 0; i < 9; i++) out += chars.charAt(buf[i] % chars.length);
          return out;
        },

步骤 3：填写 SMTP 配置并测试

163 邮箱 | smtp.163.com | 465 | SSL | 完整邮箱地址 | 邮箱授权码

授权码不是登录密码：QQ / 163 邮箱需先登录网页版 -> 设置 -> 账户 -> 开启「POP3/SMTP 服务」-> 按提示获取授权码。

升级后的验证方式
1. 车辆配置中确认已勾选「邮件」并填写正确收件邮箱。
2. 手机打开该车挪车短码页面，提交一次挪车通知。
3. 后台「通知日志」出现 channel = email、status = success 记录，收件箱数秒内收到邮件。
4. 若为 fail，可在 Worker 的 Real-time Logs 查看「SMTP 直连发信失败: xxx」的具体阶段（握手 / 认证 / 投递）。

常见失败原因对照
AUTH 授权码失败 [535]：密码填成了登录密码，或邮箱未开启 SMTP 服务。
连接握手超时：服务器地址或端口填错，或该服务商要求 587 + STARTTLS。
MAIL FROM 失败 [550]：发件邮箱与登录账号域名不一致，被服务商拒收。

发信边界说明
- 出站仅支持 465 / 587 端口，Cloudflare Workers 封锁 25 端口，请勿填写 25。
- 单次发信含 TLS 握手，耗时约 1-3 秒，运行在 ctx.waitUntil 后台，不影响挪车页面秒回。
- 原 Resend / Brevo 驱动代码保留未删，下拉中仍可切换回去，默认已改为 SMTP 直连。
- ntfy 默认 Topic 为随机串，每新增一辆车生成一个新值；同一辆车重复编辑不会改变已填 Topic。

七、 常见问题排错 (FAQ)
1. 部署后邮件全部失败，日志显示 MailChannels 拒绝
原因：MailChannels 免费转发已于 2024 年 6 月终止。处理：按第五节步骤 2、3 切换为 SMTP 直连并填写邮箱授权码。
2. 提示 Cannot find module 'cloudflare:sockets'
原因：Worker 运行时兼容日期过早。处理：Settings -> Runtime -> Compatibility Date 改为 2023-08-01 或更晚，重新部署。
3. AUTH 失败 [535]
原因：SMTP 密码填的是邮箱登录密码而非授权码，或未开启 SMTP 服务。处理：重新获取授权码后保存。
4. 收不到邮件但日志显示 success
原因：收件方邮箱把通知判为垃圾邮件，或收件地址填写有误。处理：检查垃圾箱与车辆配置中的收件邮箱。
5. ntfy 手机收不到推送
原因：Topic 与服务器地址不匹配，或自建实例缺少 Token。处理：确认服务器为 https://ntfy.sh（或自建域名）且 Topic 与手机端订阅一致；私有实例补充 Bearer Token。
6. 扫码后页面提示「该车辆挪车服务已被管理员暂停」
原因：车主账号被管理员停用。处理：管理员在【用户权限管理】重新启用该账号。
7. 能否继续使用 25 端口发信
不能。Cloudflare Workers 封锁 25 端口，仅可使用 465（SSL）或 587（STARTTLS）。
